2. DESPLIEGUE VÍA TERMINAL SSH (OPCIÓN 1 - RECOMENDADA)
═════════════════════════════════════════════════════════════════════════

PASO 1: Abrir Terminal SSH
─────────────────────────
1. Abre el hPanel: https://hpanel.hostinger.com
2. Ve a: Sitio Web → Terminal
3. Se abrirá una terminal en el navegador

PASO 2: Descargar repositorio
────────────────────────────
Ejecuta en la terminal:

cd /home/u182007214
rm -rf public_html/*  # Opcional: limpiar si hay archivos previos
git clone https://github.com/dsandovalp020-ds/tvp-minimarket.git public_html
cd public_html


PASO 3: Instalar dependencias
─────────────────────────────
Ejecuta:

composer install --no-dev --optimize-autoloader

(Esto puede tardar 2-5 minutos)


PASO 4: Configurar .env
──────────────────────
Ejecuta:

cp .env.example .env

Luego edita el archivo con nano (o vi):

nano .env

Cambios necesarios:
  • APP_URL=https://tiendago.click
  • APP_DEBUG=false
  • DB_HOST=localhost
  • DB_DATABASE=u182007214_lulu_market
  • DB_USERNAME=u182007214_lulu
  • DB_PASSWORD=P4^?ctgDn@ns  (ya configurado)

Presiona: Ctrl+O → Enter → Ctrl+X (guardar en nano)


PASO 5: Generar clave de aplicación
───────────────────────────────────
Ejecuta:

php artisan key:generate --force


PASO 6: Crear base de datos y ejecutar migraciones
──────────────────────────────────────────────────
Ejecuta:

php artisan migrate --force

(Esto crea todas las tablas automáticamente)


PASO 7: Crear enlace de storage
───────────────────────────────
Ejecuta:

php artisan storage:link


PASO 8: Limpiar y optimizar
───────────────────────────
Ejecuta:

php artisan config:cache
php artisan route:cache
php artisan view:cache
php artisan optimize


PASO 9: Configurar permisos
───────────────────────────
Ejecuta:

chmod -R 775 storage bootstrap/cache public/uploads public/backups
chmod 600 .env


PASO 10: Configurar .htaccess
─────────────────────────────
El archivo .htaccess se copia automáticamente desde deploy/

Verifica que public/index.php sea accesible:

ls -la public/index.php

Deberías ver algo como: -rw-r--r-- ... public/index.php

5. SOLUCIÓN DE PROBLEMAS
═════════════════════════════════════════════════════════════════════════

PROBLEMA: "404 Not Found" o "public/index.php not found"
─────────────────────────────────────────────────────────
SOLUCIÓN:
1. Ve a Gestor de archivos en hPanel
2. Busca el archivo: deploy/hostinger-shared-root.htaccess
3. Cópialo a la raíz del proyecto como: .htaccess
4. Si no existe, crea uno manualmente con este contenido:

<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteRule ^(.*)$ public/index.php?path=$1 [QSA,L]
</IfModule>


PROBLEMA: "SQLSTATE[HY000] [2002] No such file or directory"
──────────────────────────────────────────────────────────────
SOLUCIÓN:
1. La conexión a BD falló. Verifica en .env:
   DB_HOST=localhost
   DB_DATABASE=u182007214_lulu_market
   DB_USERNAME=u182007214_lulu
   DB_PASSWORD=P4^?ctgDn@ns
2. Si aún no funciona, usa Terminal SSH:
   mysql -u u182007214_lulu -p -h localhost
   (Ingresa contraseña)
   SHOW DATABASES;
   (Debes ver "u182007214_lulu_market")


PROBLEMA: "composer command not found"
───────────────────────────────────────
SOLUCIÓN:
1. Hostinger generalmente incluye Composer en su servidor
2. Intenta: /usr/bin/composer o /usr/local/bin/composer
3. Si aún no funciona, descarga manualmente:
   curl -sS https://getcomposer.org/installer | php
   php composer.phar install --no-dev


PROBLEMA: Las imágenes de productos no se muestran
────────────────────────────────────────────────────
SOLUCIÓN:
1. Ve a Terminal SSH
2. Ejecuta:
   cd /home/u182007214/public_html
   php artisan storage:link
3. Verifica que exista el enlace:
   ls -la public/storage
   (Deberías ver: storage -> ../storage/app/public)


PROBLEMA: El site se carga lentamente
──────────────────────────────────────
SOLUCIÓN:
1. Limpiar cachés:
   php artisan cache:clear
   php artisan config:clear
   php artisan view:clear
2. Regenerar cachés:
   php artisan config:cache
   php artisan route:cache
